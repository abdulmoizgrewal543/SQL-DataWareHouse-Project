# SQL Data Warehouse and Analytics Project

## 📌 About the Project

Hi! 👋

This is my **SQL Data Warehouse and Analytics Project**, where I built a data warehouse using Microsoft SQL Server. The purpose of this project was to practice SQL, data cleaning, ETL processes, and data modeling by working with sales data from CRM and ERP systems.

I organized the data into different layers, cleaned and transformed it, and prepared it for business analysis. I also worked on SQL queries to explore customer behavior, product performance, and sales trends.

Through this project, I gained practical experience in how data is processed and organized before it is used for reporting and decision-making.

## 🏗️ Data Architecture

The project follows the **Medallion Architecture**, which consists of three layers:

- **Bronze Layer:** Stores raw data imported from CRM and ERP CSV files.
- **Silver Layer:** Cleans and standardizes the data and handles data quality issues.
- **Gold Layer:** Organizes the processed data into fact and dimension tables for analytics.

## 🛠️ Tools and Technologies

The following tools and technologies were used in this project:

- **Microsoft SQL Server** – Database and data warehouse development.
- **SQL Server Management Studio (SSMS)** – Writing and executing SQL queries.
- **T-SQL** – Data cleaning, transformation, loading, and analysis.
- **CSV Files** – Source data from CRM and ERP systems.
- **Draw.io** – Data architecture and data modeling diagrams.
- **GitHub** – Project storage and version control.

## 🔄 Project Workflow

The project covers the following steps:

1. **Data Collection:** Worked with CRM and ERP source datasets in CSV format.
2. **Bronze Layer:** Loaded the raw data into SQL Server tables.
3. **Silver Layer:** Cleaned, standardized, and transformed the data.
4. **Gold Layer:** Created analytical models using fact and dimension tables.
5. **Data Modeling:** Organized the data into a star schema to support analytical queries.
6. **Data Quality Checks:** Checked data consistency, duplicates, and relationships where applicable.
7. **SQL Analytics:** Wrote queries to analyze sales, customers, and products.
